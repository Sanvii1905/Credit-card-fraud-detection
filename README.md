# Credit Card Fraud Detection
Final Year Project using Python, Scikit-learn and Streamlit.

## Features
- Fraud/non-fraud classification
- Data preprocessing and scaling
- Class-imbalance handling
- Logistic Regression
- Accuracy, precision, recall and F1-score
- Confusion matrix and classification report
- Streamlit prediction interface

## Run
1. Install Python 3.10+
2. `pip install -r requirements.txt`
3. `python train_model.py`
4. `streamlit run app.py`

The included CSV is a small educational synthetic dataset. It can be replaced with a compatible dataset containing `Time`, `V1`...`V28`, `Amount`, and `Class`.
